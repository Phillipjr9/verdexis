## Design System

### Brand Identity:
- **Primary Color**: #0C8B44 (Verdexis Green)
- **Secondary Color**: #0f4c81 (Deep Blue)
- **Accent Color**: #0077d9 (Bright Blue)
- **Background**: #f4f6f8 (Light Gray)
- **Text**: #1e293b (Dark Slate)
- **Success**: #16a34a (Green)
- **Warning**: #f59e0b (Amber)
- **Error**: #dc2626 (Red)
- **Info**: #0077d9 (Blue)

### Typography:
- **Font Family**: 'Segoe UI', system-ui, -apple-system, sans-serif
- **Headers**: 24px/28px/22px
- **Body**: 16px/15px
- **Small**: 13px/12px

### Layout:
- **Max Width**: 600px
- **Padding**: 28px 32px (content), 24px (header/footer)
- **Border Radius**: 12px (container), 8px (cards/buttons)
- **Shadows**: 0 4px 6px rgba(0,0,0,0.05)

### Components:
1. **Header**: Gradient background, logo, title, optional subtitle
2. **Alert Banners**: Success/Warning/Error/Info with icons
3. **Info Cards**: Bordered boxes for transaction details
4. **Buttons**: Primary (#0C8B44), Secondary (outlined), Danger
5. **Data Tables**: For transaction/asset lists
6. **Footer**: Company info, links, social media, legal

## Implementation Plan

### Phase 1: Create Professional Base Template
Create `server/templates/email_base.html` as the foundation for all emails with:
- Responsive design
- Dark mode support
- Professional header with Verdexis branding
- Consistent footer with all necessary links
- CSS variables for easy theming

### Phase 2: Update All Existing Templates
Update each template to use the new design system:
1. email_welcome.html - Modern onboarding experience
2. email_otp_verification.html - Clean security code display
3. email_transaction_confirmation.html - Professional transaction receipt
4. email_security.html - Alert-focused design
5. email_portfolio_alert.html - Investment-focused alerts
6. email_error_notification.html - Clear error communication

### Phase 3: Create Missing Templates
Create new templates for:
