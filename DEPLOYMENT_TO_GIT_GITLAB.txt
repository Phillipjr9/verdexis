TROUBLESHOOTING:
==============

If push fails with authentication error:
1. Check GitHub credentials are configured
2. Check GitLab access token is valid
3. Verify SSH keys or HTTPS credentials

If push fails with "Branch protection":
1. Merge is required instead of direct push
2. Create pull request on GitHub
3. Create merge request on GitLab

If Render deployment fails after push:
1. Check Render build logs
2. Verify DATABASE_URL is set correctly in Render
3. Check for TypeScript compilation errors
4. Verify migrations can run

REVERTING A DEPLOYMENT:
=====================

If something goes wrong:

GitHub:
1. Go to repository
2. Click "Commits"
3. Find previous working commit
4. Click "Browse files" → Copy commit hash
5. Run: git reset --hard [commit-hash]
6. Run: git push origin main --force

GitLab:
Same process but on gitlab.com
