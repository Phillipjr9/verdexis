COMMON ISSUES & FIXES:
====================

Issue: Database connection failed

Solution 1: Check RDS security group
  - AWS Console → RDS → Databases
  - Select database → Security group
  - Inbound rule: Port 5432, Source 0.0.0.0/0

Solution 2: Verify DATABASE_URL in Render
  - Render Dashboard → Environment
  - Check DATABASE_URL exact value
  - Ensure ?sslmode=require is present

Solution 3: Test connection locally first
  - Run: .\test-rds-connection.ps1 (Windows)
  - Run: bash test-rds-connection.sh (Mac/Linux)

---

Issue: Build fails with TypeScript errors

Solution: Clear build cache in Render
  - Render Dashboard → Settings
  - Click "Clear Build Cache"
  - Redeploy

---

Issue: Service keeps restarting

Solution: Check npm start:migrate output
  - Click "Logs" in Render
  - Look for Prisma errors
  - Check migrations exist in server/prisma/migrations/

---

Issue: API responds with 503 Service Unavailable

Solution: Database not ready
  - Check Render logs for "Database connected"
  - May take 30-60 seconds on first deploy
  - Reload page after 1 minute

PRISMA SCHEMA SYNC:
==================

If database schema is missing:

1. Locally, run:
   cd server
   npx prisma migrate deploy

2. Or manually in psql:
   psql "postgresql://postgres:password@host:5432/postgres"
   
   Then run Prisma schema creation:
   npx prisma db push --skip-generate
