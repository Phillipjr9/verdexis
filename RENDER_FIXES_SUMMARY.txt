TROUBLESHOOTING:
===============

If database connection fails after deployment:

1. Check Render logs
   Dashboard → Logs
   Look for "Database connected successfully" message

2. Verify DATABASE_URL in Render environment
   Dashboard → Environment
   Check exact value matches provided URL

3. Test RDS locally
   .\test-rds-connection.ps1

4. Check RDS security group
   AWS → RDS → Security Groups
   Inbound: Port 5432 from 0.0.0.0/0

5. Common issues:
   - SSL mode: Must be "require" for RDS
   - Schema: Must be "public"
   - Password: Must be URL-encoded
   - Host: Must be full RDS endpoint

See RENDER_DEPLOYMENT_CHECKLIST.txt for more troubleshooting.

IMPORTANT NOTES:
===============

1. RDS must be publicly accessible
   AWS → RDS → Modify Instance
   → Enable "Public accessibility"

2. Security group must allow port 5432
   AWS → RDS → Security Groups
   → Inbound rule: Type PostgreSQL, Source 0.0.0.0/0

3. Database credentials in URL are encoded
   Original: S5C<K#5-K)|J8_K:O:o)GZ<mIkI*
   Encoded: S5C%3CK%235-K%29%7CJ8_K%3AO%3Ao%29GZ%3CmIkI%2A

4. SSL is required for RDS connections
   Always include: ?sslmode=require

5. First deploy may take 5-10 minutes
   Build time + database migrations
