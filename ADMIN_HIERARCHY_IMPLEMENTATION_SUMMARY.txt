COMPLETE FEATURE SET
================================================================================

API Endpoints (All Authentication Protected):
├── POST   /api/admin/hierarchy/admins                    (Create sub-admin)
├── GET    /api/admin/hierarchy/admins                    (List sub-admins)
├── GET    /api/admin/hierarchy/admins/:adminId           (Get admin details)
├── GET    /api/admin/hierarchy/admins/:adminId/users     (List admin's users)
├── POST   /api/admin/hierarchy/assign-user               (Assign user)
└── POST   /api/admin/hierarchy/remove-assignment         (Remove assignment)

Permission Model:
├── Super Admin:
│   ├── Can create sub-admins
│   ├── Can view all sub-admins
│   ├── Can manage all users
│   ├── Can assign/reassign any user
│   └── Full permissions
├── Sub-Admin:
│   ├── Cannot create other admins
│   ├── Can manage assigned users only
│   ├── Can view own assigned users
│   └── Limited permissions by design
└── Regular User:
    ├── No admin privileges
    ├── Auto-assigned to default admin
    └── Can be reassigned by Super Admin

Database Models:
├── AdminHierarchy
│   ├── adminId (Primary Key)
│   ├── parentAdminId (Foreign Key)
│   ├── canCreateAdmins (Boolean)
│   ├── canManageUsers (Boolean)
│   ├── canManageDeposits (Boolean)
│   ├── canManageTransactions (Boolean)
│   └── createdBy (Foreign Key)
└── UserAdminAssignment
    ├── userId (Primary Key, Unique)
    ├── adminId (Primary Key)
    ├── assignedBy (Foreign Key)
    └── assignedAt (Timestamp)
