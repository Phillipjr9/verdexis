TROUBLESHOOTING:
==============

If database connection still fails:

1. Check DATABASE_URL in Render
   Dashboard → Environment
   Verify password matches exactly

2. Verify RDS is accessible
   AWS → RDS → Databases
   Status: available
   Publicly accessible: Yes

3. Check RDS security group
   Port 5432 from 0.0.0.0/0

4. Review Render logs
   Dashboard → Logs
   Look for error messages

If build fails:

1. Check Node.js version (must be >=20)
2. Clear build cache:
   Dashboard → Settings → Clear Build Cache
3. Check TypeScript errors in logs
4. Verify all dependencies installed

If API not responding:

1. Wait 1-2 minutes for startup
2. Refresh page
3. Check Render is running (not restarting)
4. Check PORT is 4000
