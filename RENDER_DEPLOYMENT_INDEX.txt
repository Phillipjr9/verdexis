QUICK START (5 MINUTES):
=======================

   .\test-rds-connection.ps1

2. Copy environment variables:
   → Open RENDER_ENV_VARS_COPY_PASTE.txt
   → Copy all KEY/VALUE pairs

3. Set up Render service:
   → Go to https://render.com
   → New → Web Service
   → Connect GitHub repo

4. Configure in Render:
   Build Command: cd server && npm install && npm run build
   Start Command: cd server && npm run start:migrate
   Add all environment variables from step 2

5. Deploy:
   Click "Create Web Service"
   Wait for build to complete

6. Verify:
   curl https://[service].onrender.com/api/health
