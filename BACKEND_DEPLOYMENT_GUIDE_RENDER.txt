PHASE 1: RENDER SETUP & DATABASE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Create Render Account (If needed)
  [ ] Go to https://dashboard.render.com
  [ ] Sign up / Log in
  [ ] Create new project

STEP 2: Create PostgreSQL Database
  [ ] On Render dashboard, click "New +"
  [ ] Select "PostgreSQL"
  [ ] Database name: verdexis_db
  [ ] Region: Select closest region
  [ ] PostgreSQL version: Latest (14+)
  [ ] Click "Create Database"
  [ ] Wait for database to be ready (2-3 minutes)
  [ ] Copy the connection string (External Database URL)

STEP 3: Copy Database URL
  [ ] The URL will look like:
      postgresql://user:password@dpg-xxx.render.com:5432/verdexis_db
  [ ] SAVE THIS - You'll need it soon

STEP 4: Create Web Service
  [ ] On Render dashboard, click "New +"
  [ ] Select "Web Service"
  [ ] Connect to GitHub repository
  [ ] Select: your-verdexis-repo
  [ ] Service name: verdexis-backend
  [ ] Environment: Node
  [ ] Build command: cd server && npm install && npx prisma generate && npx tsc -p tsconfig.json --skipLibCheck
  [ ] Start command: cd server && npm run start
  [ ] Region: Select same as database
  [ ] Plan: Free (or upgrade if needed)
  [ ] Create Web Service

STEP 5: Set Environment Variables (Render Dashboard)
  [ ] Go to Web Service settings > Environment
  [ ] Add variables:

      NODE_ENV = production
      PORT = 4000
      DATABASE_URL = [PASTE THE URL FROM STEP 3]
      JWT_SECRET = [GENERATE: openssl rand -hex 32]
      JWT_EXPIRES_IN = 7d
      CORS_ORIGIN = https://main.d28t5x0lqjdtjj.amplifyapp.com
      APP_BASE_URL = https://main.d28t5x0lqjdtjj.amplifyapp.com
      
      OPTIONAL (if using AWS SES for email):
      AWS_REGION = us-east-1
      SES_FROM_EMAIL = noreply@verdexis.com
      AWS_ACCESS_KEY_ID = [your key]
      AWS_SECRET_ACCESS_KEY = [your secret]

  [ ] Click "Save Environment Variables"
  [ ] Render will auto-redeploy

PHASE 2: ADD SECURITY FEATURES TO BACKEND
═══════════════════════════════════════════════════════════════════════════════

STEP 6: Copy Security Files to Backend
  [ ] Copy these 6 files to server/src/services/:
      1. password-reset-complete.js
      2. email-notifications-complete.js
      3. rate-limiting-complete.js
      4. security-service-complete.js
      5. api-routes-complete.js → copy to server/src/routes/
      6. Update: admin-panel.js

  Command:
  cp password-reset-complete.js server/src/services/
  cp email-notifications-complete.js server/src/services/
  cp rate-limiting-complete.js server/src/services/
  cp security-service-complete.js server/src/services/
  cp api-routes-complete.js server/src/routes/
  # Update admin-panel.js manually

STEP 7: Update package.json
  [ ] Add new dependencies to server/package.json:
      
      In "dependencies":
      "express-rate-limit": "^7.1.5",
      "speakeasy": "^2.0.0",
      "qrcode": "^1.5.3",
      "uuid": "^9.0.1"

  [ ] Install locally:
      cd server
      npm install

STEP 8: Update Server app.ts/app.js
  [ ] Add imports at top:
      import apiRoutesComplete from './routes/api-routes-complete.js';
      import securityMiddleware from './middleware/security-middleware.js';

  [ ] Add middleware after express setup:
      app.use(securityMiddleware);

  [ ] Add routes:
      app.use('/api', apiRoutesComplete);

  [ ] Verify your existing routes are still there

STEP 9: Create Security Middleware
  [ ] Create file: server/src/middleware/security-middleware.ts
  
      Contents:
      import { BruteForceProtection } from '../services/rate-limiting-complete.js';
      
      const bruteForce = new BruteForceProtection();
      
      const securityMiddleware = (req, res, next) => {
        req.startTime = Date.now();
        req.ip = req.headers['x-forwarded-for']?.split(',')[0].trim() ||
                 req.socket.remoteAddress;
        
        console.log({
          timestamp: new Date().toISOString(),
          method: req.method,
          path: req.path,
          ip: req.ip
        });
        
        next();
      };
      
      export default securityMiddleware;

STEP 10: Update Prisma Schema (if needed)
  [ ] Add custom attributes to User model in schema.prisma:
      
      model User {
        // ... existing fields
        
        // 2FA attributes
        twoFactorEnabled    Boolean @default(false)

        // KYC attributes

  [ ] Run migration:
      npx prisma migrate dev --name add_security_fields
  
  [ ] Push to database:
      npx prisma db push

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: Build Fails
  [ ] Check logs for error message
  [ ] Verify all dependencies in package.json
  [ ] Check TypeScript compilation
  [ ] Verify npm scripts are correct

ISSUE: Service Won't Start
  [ ] Check logs for startup errors
  [ ] Verify DATABASE_URL is correct
  [ ] Verify port 4000 is not in use
  [ ] Check Node.js version (needs >= 20)

ISSUE: Cannot Connect to Database
  [ ] Verify DATABASE_URL is set in environment
  [ ] Check Postgres is running
  [ ] Verify connection string format
  [ ] Check credentials are correct

ISSUE: Rate Limiting Not Working
  [ ] Verify rate-limiting-complete.js is in services
  [ ] Check middleware is applied
  [ ] Verify environment variables are set
  [ ] Check logs for rate limit events

ISSUE: Emails Not Sending
  [ ] Verify SES credentials are set
  [ ] Check SES is out of sandbox mode
  [ ] Verify sender email is verified
  [ ] Check CloudWatch logs for errors

ISSUE: CORS Errors
  [ ] Verify CORS_ORIGIN matches frontend URL
  [ ] Check CORS headers in app.ts
  [ ] Verify frontend is making correct requests
  [ ] Check browser console for details
