BUILD & START COMMANDS:
======================

Build Command:
cd server && npm install && npm run build

Start Command:
cd server && npm run start:migrate

===========================

HOW TO ADD TO RENDER:
====================

1. Go to https://dashboard.render.com
2. Select your web service
3. Go to "Environment" tab
4. Click "Add Environment Variable"
5. Copy KEY from above
6. Paste into "Name" field
7. Copy VALUE from above
8. Paste into "Value" field
9. Click "Save"
10. Repeat for each variable

===========================

VERIFY DEPLOYMENT:
==================

After all variables are set and build completes:

curl https://[your-render-service-name].onrender.com/api/health

Should return:
{
  "ok": true,
  "service": "verdexis-api",
  "database": "Connected",
  "databaseReady": true
}
