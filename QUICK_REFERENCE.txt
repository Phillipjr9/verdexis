1️⃣  PASSWORD RESET - Forgot Password Flow
═══════════════════════════════════════════════════════════════════════════════

USER FLOW:
1. User clicks "Forgot Password"
2. Enters email
3. Receives email with reset link (expires in 1 hour)
4. Clicks link, enters new password
5. Password updated, confirmation email sent

API ENDPOINTS:
POST   /api/password/forgot          → Initiate reset (rate limited: 3/hour)
POST   /api/password/reset           → Complete reset with token
POST   /api/password/change          → Change existing password

CURL EXAMPLES:

# Initiate forgot password
curl -X POST https://main.d28t5x0lqjdtjj.amplifyapp.com/api/password/forgot \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com"}'

# Reset password with token
curl -X POST https://main.d28t5x0lqjdtjj.amplifyapp.com/api/password/reset \
  -H "Content-Type: application/json" \
  -d '{"token":"xxx","newPassword":"NewPass123!@#"}'

PASSWORD REQUIREMENTS:
✓ Minimum 12 characters
✓ Uppercase letters (A-Z)
✓ Lowercase letters (a-z)
✓ Numbers (0-9)
✓ Special characters (!@#$%^&*)

4️⃣  TWO-FACTOR AUTHENTICATION (2FA) - Extra Security
═══════════════════════════════════════════════════════════════════════════════

SUPPORTED METHODS:
🔐 TOTP (Time-based One-Time Password)
   • Use with Google Authenticator, Authy, Microsoft Authenticator
   • QR code for easy setup
   • 6-digit codes that refresh every 30 seconds

📱 SMS (Short Message Service)
   • 6-digit codes sent via SMS
   • 5-minute expiration

🔑 Backup Codes
   • 10 recovery codes
   • One-time use
   • For account recovery if authenticator lost

API ENDPOINTS:
POST   /api/security/2fa/enable       → Start 2FA setup
POST   /api/security/2fa/confirm      → Verify and confirm
POST   /api/security/2fa/disable      → Disable 2FA

LOGIN WITH 2FA:
1. Normal login → Username & password
2. System checks if 2FA enabled
3. If enabled → Request 2FA code
4. User enters code from authenticator/SMS
5. Login complete
