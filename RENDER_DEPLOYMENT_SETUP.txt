Step 3: Configure Build Settings
  Build Command: cd server && npm install && npm run build
  Start Command: cd server && npm run start:migrate
  Runtime: Node
  Plan: Free/Paid

Step 4: Important RDS Configuration
  
  A. Ensure RDS Security Group allows inbound on port 5432
     Source: 0.0.0.0/0 (or Render's IP range)
  
  B. Verify RDS is publicly accessible
     In AWS RDS Dashboard → Connectivity & security
     → Publicly accessible: Yes
  
  C. SSL Mode
     The database URL includes ?sslmode=require
     This is required for RDS connections

Step 5: Deploy
  1. Click "Create Web Service"
  2. Render will automatically deploy on git push
  3. Check deployment logs at: https://dashboard.render.com/logs

Step 6: Verify Deployment
  Check the logs for:
  ✅ Database connected successfully
  ✅ Server listening on port 4000
  
  If database connection fails:
  - Verify DATABASE_URL in Render env vars
  - Check RDS security groups
  - Test connection locally with psql first

Database Connection Troubleshooting
===================================

If you see "Database connection failed":

1. Verify DATABASE_URL format:
   postgresql://user:password@host:5432/dbname?sslmode=require

2. Check RDS Details:
   - Host: database-2-instance-1.c0xwa6wyga3m.us-east-1.rds.amazonaws.com
   - Port: 5432
   - User: postgres
   - Database: postgres
   - Password: URL-encoded version

3. Test Connection Locally:
   psql "postgresql://postgres:password@database-2-instance-1.c0xwa6wyga3m.us-east-1.rds.amazonaws.com:5432/postgres?sslmode=require"

4. Check Render Logs:
   - New connections
   - SSL errors
   - Authentication errors

Deployment Status Commands
===========================

Check deployment status:
  render logs --tail 100

Restart service:
  render restart

View environment:
  render env list

Update environment variable:
  render env set KEY=value

Deploy from specific commit:
  1. In Render dashboard
  2. Click "Manual Deploy"
  3. Select commit

Notes
=====

- Free tier may have limitations
- Database migrations run automatically on deploy
- First deploy may take 5-10 minutes
- SSL is required for RDS connections
- Check Render logs if deployment fails
