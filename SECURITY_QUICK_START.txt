🚀 INTEGRATION STEPS
====================

1. Install Dependencies
   npm install

2. Copy Files to Server
   - Copy all *-complete.js files to server/src/
   - Update admin-panel.js
   - Copy api-routes-complete.js

3. Update Express App (server/src/app.ts or app.js)
   
   const express = require('express');
   const apiRoutes = require('./api-routes-complete');
   const app = express();
   
   app.use(express.json());
   app.use('/api', apiRoutes);

4. Initialize Security Service (in app startup)
   
   const ComprehensiveSecurityService = require('./security-service-complete');
   const security = new ComprehensiveSecurityService();
   
   // Cleanup expired tokens hourly
   setInterval(() => {
     security.cleanup();
   }, 60 * 60 * 1000);

5. Configure AWS Services
   - Verify sender email in AWS SES
   - Ensure SES has production access (not sandbox)
   - Configure Cognito user pool
   - Create necessary custom attributes

6. Test All Features
   npm test


📚 API USAGE EXAMPLES
=====================

1. User Registration & Welcome Email
   
   POST /api/auth/register
   {
     "email": "user@example.com",
     "password": "SecurePass123!@#",
     "name": "John Doe"
   }

2. Password Reset Flow
   
   // Step 1: Request reset
   POST /api/password/forgot
   {
     "email": "user@example.com"
   }
   
   // User receives email with link containing token
   // User visits: https://verdexis.com/reset-password?token=xxx
   
   // Step 2: Complete reset
   POST /api/password/reset
   {
     "token": "xxx",
     "newPassword": "NewSecurePass123!@#"
   }

3. Enable 2FA
   
   POST /api/security/2fa/enable
   {
     "email": "user@example.com",
     "method": "totp"
   }
   
   Response includes QR code to scan with authenticator

4. Admin Dashboard
   
   GET /api/admin/dashboard
   
   Returns summary of users, alerts, statistics

5. Suspend User
   
   POST /api/admin/users/user@example.com/suspend
   {
     "reason": "Suspicious activity detected"
   }

6. Get Audit Logs
   
   GET /api/security/audit-logs/user@example.com?limit=100
   
   Returns all user actions

❓ TROUBLESHOOTING
==================

Issue: Emails not sending
Fix:
1. Verify AWS SES sender email is verified
2. Check AWS SES is in production (not sandbox)
3. Review CloudWatch logs
4. Verify AWS_REGION in .env

Issue: 2FA not working
Fix:
1. Check system time synchronization
2. Verify TOTP secret generation
3. Test with backup codes
4. Review user 2FA status

Issue: Rate limiting errors
Fix:
1. Check IP address detection
2. Verify rate limit window settings
3. Review brute force protection status

Issue: Audit logs disk space
Fix:
1. Run security.cleanup() regularly
2. Archive old logs to S3
3. Adjust retention period
